# 📈 Optimization & Numerical Root-Finding

This module focuses on continuous optimization and numerical root-finding algorithms from first principles:

* **Newton-Raphson on Semiconductor Quantum Wells:** Solves transcendental boundary condition equations from the time-independent Schrödinger equation to extract discrete energy levels and effective electron masses ($m^*$).
* **First-Order Gradient Optimizers:** Implementation and convergence comparison between:
  * Standard Gradient Descent (GD)
  * Gradient Descent with Momentum (GDM)
  * Nesterov Accelerated Gradient (NAG)
