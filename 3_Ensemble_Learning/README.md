# 🌲 Ensemble Learning & Physics Applications

Combining multiple weak learners to build high-performance predictive models:

* **Ensemble Benchmarks:** Implementation and evaluation of Bagging, Boosting (AdaBoost/Gradient Boosting), and Voting Classifiers.
* **Phase Classification in the 2D Ising Model:** Using ensemble architectures to classify magnetic phase configurations and critical temperature transitions in statistical mechanics lattice simulations.
