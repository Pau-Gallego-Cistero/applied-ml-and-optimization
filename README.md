# Applied Machine Learning & Numerical Methods

A comprehensive portfolio covering core numerical optimization, classical machine learning algorithms from scratch and deep learning, and their applications to physical systems.

Developed as part of the **Artificial Intelligence & Physics** curriculum at **Universidad Europea de Valencia**.

---

## Tech Stack
* **Languages:** Python
* **Libraries:** `scikit-learn`, `numpy`, `scipy`, `pandas`, `matplotlib`, `sympy`
* **Core Domains:** Numerical Optimization, Supervised Learning, Unsupervised Learning, Ensemble Methods, Data Cleaning & Preprocessing

---

## 📂 Repository Architecture

| Module | Core Concepts | Highlights & Physical Applications |
| :--- | :--- | :--- |
| **[📈 1_Optimization_and_Root_Finding](./1_Optimization_and_Root_Finding/)** | Newton-Raphson, Gradient Descent (GD, GDM, NAG) | Transcendental quantum well solver & convex optimization benchmark |
| **[📉 2_Regression_and_Regularization](./2_Regression_and_Regularization/)** | OLS, Ridge (L2), LASSO (L1), Scikit-Learn | Regularization parameter tuning & fitting linear physical laws (Hooke's Law) |
| **[🌲 3_Ensemble_Learning](./3_Ensemble_Learning/)** | Bagging, AdaBoost, Gradient Boosting, Voting | Bias-variance tradeoff analysis and multi-model classification benchmarks |
| **[🧹 4_Data_Cleaning_Exoplanets](./4_Data_Cleaning_Exoplanets/)** | Data sanitization, corrupt value handling, pipeline robustness | Automated cleaning and validation pipeline for the Open Exoplanet Catalogue (OEC) |
| **[🔍 5_Unsupervised_Learning](./5_Unsupervised_Learning/)** | Clustering (K-Means, DBSCAN), Dimensionality Reduction (PCA) | Unlabeled pattern discovery, feature space compression, and anomaly detection |
| **[🧠 6_Deep_Learning](./6_Deep_Learning/)** | Multi-Layer Perceptrons (MLP), Backpropagation, Loss Landscapes | Neural network architectures for nonlinear function approximation and physical modeling |
