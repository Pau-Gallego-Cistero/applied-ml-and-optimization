# 📉 Regression & Regularization Techniques

Exploration of linear regression, over-fitting mitigation, and sparsity induction:

* **OLS vs. Ridge vs. LASSO:** Comparative study of Ordinary Least Squares, $L_2$ shrinkage (Ridge), and $L_1$ feature selection (LASSO) using synthetic and benchmark datasets.
* **Physics Application (Hooke's Law):** Using regularized regressions to estimate elastic constants and physical parameters from noisy experimental measurements.
